omarchy-color-theme.json.tpl is Omarchy's VS Code color theme template
(default/themed/vscode-theme.json.tpl in https://github.com/basecamp/omarchy),
Copyright (c) David Heinemeier Hansson, MIT License; the full license text is
packaging/OMARCHY-LICENSE.txt. Omarchy Overlay fills it from the current theme's
colors.toml (src/vscode_theme.rs) and installs the result as a local VS Code theme.
